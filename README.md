# Sistema de Facturación para la Carnicería AL CORTE

## Descripción del proyecto

Sistema de facturación desarrollado para el expendio de carnes AL CORTE como proyecto formativo del Servicio Nacional de Aprendizaje (SENA).

El sistema busca apoyar la gestión de las ventas, los productos, el inventario y los clientes, facilitando el registro y la consulta de la información del negocio.

## Objetivo

Desarrollar una aplicación web que permita organizar y mejorar los procesos de facturación y control comercial de la carnicería AL CORTE.

## Tecnologías

- Python
- Flask
- MySQL
- HTML
- CSS
- Visual Studio Code
- Git y GitHub

## Módulos previstos

- Inicio de sesión y control de acceso.
- Gestión de productos y categorías.
- Control de inventario.
- Registro de clientes.
- Registro y consulta de facturas.
- Reportes de ventas.
- Gestión de usuarios y permisos.
- Administración de proveedores.

## Estado del proyecto

Proyecto en fase inicial de organización y desarrollo.

## Autoría

Proyecto formativo del SENA.
